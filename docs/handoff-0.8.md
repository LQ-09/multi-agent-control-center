# 0.8 independent quota window

Tauri creates a second bundled webview, usage, with a query-routed React entry point, always-on-top/all-workspaces flags and a draggable header. It shares the existing Python broker; its RPC is restricted to agent_status. Updating is restricted to main. Window close hides rather than destroys either window; macOS Dock reopen restores main, while Quit still tears down the broker.

QuotaRing uses custom inline vector icons and remaining-percentage arc length. Boundary behavior: >70 green, 30–70 orange, <30 red, unknown grey; labels preserve window/scope and stale/restricted warnings. Polling uses cached monitor results, not paid inference. The widget lists local/remote accounts according to the selected execution layout. Main language/font/theme changes synchronize through storage events. Geometry does not persist across relaunch.

Checks: frontend build and rendered ring/boundary tests, 50 Python tests, source and frozen backend simulated smoke, native release build/signature checks. Actual GUI dragging, Space behavior, close/reopen and installed updater need manual verification; this build environment has not demonstrated GUI interaction or real subscription quota availability.
